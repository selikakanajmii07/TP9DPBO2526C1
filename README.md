PENJELASAN
DESAIN DAN FUNGSI PROGRAM
Program terbagi tiga bagian:
- Model, berfungsi untuk mengelola data dan melakukan komunikasi dengan database, seperti mengambil, menambah, mengubah, dan menghapus data.
- View, berfungsi untuk menampilkan data dan form kepada pengguna menggunakan template HTML.
- Presenter, berfungsi sebagai penghubung antara Model dan View serta mengatur alur program.
Setiap bagian menggunakan interface atau kontrak agar komunikasi antarbagian lebih terstruktur.

FITUR PROGRAM
1. Data Kandidat
- Menampilkan daftar kandidat karyawan.
- Menambahkan data kandidat baru.
- Mengubah data kandidat.
- Menghapus data kandidat.

2. Data Departemen
- Menampilkan daftar departemen.
- Menambahkan departemen baru.
- Mengubah nama dan deskripsi departemen.
- Menghapus data departemen.
  
STRUKTUR PROGRAM
- models, berisi class Model, database, dan interface untuk Kandidat.
- views, berisi class View dan interface Kandidat.
- presenters, berisi class Presenter dan interface Kandidat.
- template, berisi template HTML untuk halaman Kandidat.
- departemen, berisi seluruh bagian Model, View, Presenter, interface, dan template untuk fitur Departemen.
- index.php digunakan sebagai halaman utama untuk mengatur alur program.
